# AGENTS.md

## 写作规则

- **简洁**：直陈结论，不写背景铺垫和过渡性填充；能用表格或清单表达的，不写成大段文字。
- **一处定义**：每个设计点（路由、路径规则、错误码、生命周期、边界语义等）只在最贴切的一处完整定义一次。
- **其余引用**：其它文档只以相对链接引用，不复述、不改写；同一文档内同样不重复，不要让表格、清单和正文把同一点讲三遍。
- **风格一致**：同类内容在各文档中用相同的结构和措辞，如端点清单、错误表、术语。
- **术语一致**：同一概念始终使用同一术语。

分工示例：路径模型归 [FileSystem.md](./FileSystem.md)，路由约定归 [Workspace.md](./Workspace.md)，其它文档只链接引用，不重述。
